# Suckless Installer

Instalador automático para mi configuración personalizada de **DWM**, **ST** y **DMENU** con todas las dependencias, fuentes y scripts necesarios.

---

## 📋 Características

- ✅ Instalación automática de DWM, ST y DMENU
- ✅ JetBrains Mono Nerd Font (fuente con iconos)
- ✅ Fondo de pantalla predeterminado
- ✅ Script de autostart para DWM
- ✅ Creación automática de `~/.xinitrc`
- ✅ Soporte para audio con pipewire-audio
- ✅ Manejo de errores y actualizaciones
- ✅ Soporte para Debian/Ubuntu

---

## Requisitos previos

- Git (para clonar) o descargar ZIP
- Conexión a internet
- Linux (Debian/Ubuntu)

## Instalación

### Clonar con Git (recomendado)

```bash
git clone https://github.com/ichardsc/suckless-installer.git
cd suckless-installer
chmod +x install.sh
./install.sh
```
